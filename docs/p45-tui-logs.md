# TUI 日志浏览

工作流页按 `l` 打开日志二级页面；`Esc` / `q` 返回原页面，不取消任务。

- `Tab` / `Shift-Tab`：选择日志来源。
- `↑` / `↓`、`PgUp` / `PgDn`：滚动当前块；`←` / `→`：横向滚动。
- `n` / `p`：下一块 / 上一块；`Home` / `End`：当前块首 / 块尾。
- `r`：刷新；打开日志期间每秒自动重新读取当前块。

安装页提供 `.rospm/log/apply.log`、`uninstall.log`、`deps.log` 和
`conda.log`；编译页提供已有的 `build.log`。apply、uninstall、deps install
的外部 `Run` 命令现在通过共享执行器转发并保存 stdout / stderr，包含命令、
工作目录和退出状态；dry-run 和拒绝卸载确认不会创建日志。
这些兼容日志在每次实际执行首个记录命令时覆盖，不代表任务历史。
Conda 内部步骤尚未统一写入独立日志；运行和调试工作流也尚未接入执行端。
来源不存在时显示路径和读取错误，不伪造日志或声称日志完整。

已有 worker 日志 `.rospm/tasks/<task-id>/logs.jsonl` 独立作为任务来源展示，
保留 cursor、stdout / stderr / worker 标识。当前快照无工作流字段，因此
任务来源在各工作流日志页均可选择，不根据任务名或输出文本猜测其归属。

每次最多读取 64 KiB，按块浏览完整文件，绘制当前可见行。超长 JSONL
记录或损坏记录显示解析错误；原始文件保持原样。原始终端控制字符显示为
空格，不把日志内容作为终端指令执行。刷新当前块不会跳转或合并其他来源。
