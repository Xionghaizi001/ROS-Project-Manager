# P4.5.2 worker 日志管线

日期：2026-10-31。

`rospm-core::worker::LogPump` 为 stdout 和 stderr 各建立读取线程。读取到的每一行先追加到任务的 `logs.jsonl`，再尝试进入 UI 队列；磁盘写入失败会从读取线程返回错误，调用方必须把任务标记为日志不完整或失败，不能继续报告完整日志。

UI 队列同时限制条目数和文本字节数。队列满时采用非阻塞淘汰最旧 UI 条目，并累计 `dropped_count`；任务日志仍然完整落盘，因此慢客户端、断连或 UI 发送失败不会阻塞子进程读取。UI 重连后可用任务日志游标补读被淘汰的条目。读取线程结束只表示对应流到达 EOF，最终任务结果仍由 worker 单独写入快照。
